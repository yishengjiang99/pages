# 100 Pages

One hundred standalone HTML pages, each a different idea and visual style: shaders, generative canvas art, CSS illustration, SVG, small games, audio toys, print-inspired layouts and UI parodies.

- Every page is a single self-contained `.html` file with inline CSS and JS. The only external requests are Google Fonts.
- No images, no libraries, no tracking.
- `index.html` is the gallery. It has filters by technique, hover previews and a random button.

Live: https://yishengjiang99.github.io/pages/creative/
